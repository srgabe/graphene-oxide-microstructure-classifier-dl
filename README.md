# graphene-oxide-microstructure-classifier-dl
Classificação Automática de Micrografias MEV de Óxido de Grafeno e Grafite usando Deep Learning com TensorFlow. O projeto aplica Transfer Learning e Data Augmentation para treinar uma Rede Neural Convolucional (CNN) robusta com um dataset limitado, automatizando a identificação de fases na síntese de nanomateriais.
